## 风险与对策

| 风险 | 对策 |
|---|---|
| 子代理产出接口与契约不符 | T0 冻结 `server.js` 路由表 + spec §7，子代理只实现 handler |
| 并行写同一文件冲突 | 严格文件所有权清单（见 todo.md 的 Files 字段），`server.js` 归 T0 |
| 种子数据质量（史实错/年份错） | 要求只用公认事件；不确定的用 `circa/disputed` 标注；≤3% 容错 |
| PGlite 无 PostGIS/tsvector | 用 lat/lon 包围盒 + LIKE；已在 spec §9 记为升级项 |
| 前端无打包，模块解析失败 | 统一用相对路径 `./x.js`；vendor 用 importmap 或全局脚本 |
